# 🤝 Community contributions

This is where students share what they've built on top of GradeWise. Browse for ideas, and add your own!

**To contribute:** create `community_contributions/<your-github-username>/`, put your work there with a short README, clear notebook outputs, and open a Pull Request. Full steps: [CONTRIBUTING.md](../CONTRIBUTING.md).

Ideas to get you started:
- 🌍 GradeWise for another subject or language
- 🧮 Grading numerical answers with step-by-step partial credit
- 🤖 A second "moderator" grader for borderline marks (week 5 exercise)
- 📈 A class-analytics dashboard
- 🔌 An MCP server that exposes GradeWise to other agents
