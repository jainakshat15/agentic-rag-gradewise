## Unit 1: Operating Systems

**Question 1**

What is a *system call*? Explain why the CPU switches from user mode to kernel mode when a system call is made. **[3 marks]**

**Question 2**

(a) Define a *process*. **[2 marks]**

(b) Give THREE differences between a process and a thread. **[3 marks]**

**Question 3**

What is a deadlock? Name TWO of the four necessary conditions for a deadlock. **[4 marks]**

**Question 4**

(a) What is a *race condition*? **[2 marks]**

(b) Explain how a semaphore is used for synchronisation. Your answer should describe the wait() and signal() operations and the difference between a binary and a counting semaphore. **[4 marks]**

**Question 5**

A system has 32-bit logical addresses, a page size of 8 KB and page-table entries of 4 bytes. Calculate (i) the number of bits used for the page offset, (ii) the number of pages in the logical address space, and (iii) the size of a single-level page table for one process. Show your working. **[5 marks]**

## Unit 2: Computer Networks

**Question 6**

(a) Describe the TCP three-way handshake used to open a connection. **[3 marks]**

(b) Give TWO differences between TCP and UDP, and name ONE application that is better suited to UDP, explaining why. **[3 marks]**

**Question 7**

A server on a company network has the IP address **172.16.45.200/27**.

(a) How many usable host addresses does this subnet provide? Show your working. **[2 marks]**

(b) Find the network address and the broadcast address of this subnet, and state its subnet mask in dotted-decimal form. **[3 marks]**

**Question 8**

A student types **www.northbridge.edu** into a browser on a computer that has never visited the site. Explain, step by step, how DNS resolves this name to an IP address. **[5 marks]**

## Unit 3: Database Systems

**Question 9**

State and briefly explain the four ACID properties of a database transaction. **[4 marks]**

**Question 10**

(a) Explain the difference between a *primary key* and a *foreign key*, using an example. **[3 marks]**

(b) The table below has the composite primary key (student_id, course_code):

`Enrolment(student_id, course_code, student_name, course_title, grade)`

Explain why this table is not in second normal form (2NF), show how you would decompose it into 2NF, and name ONE anomaly that the original table suffers from. **[4 marks]**
